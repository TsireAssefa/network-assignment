# Network Security & Scanning Assignments

This repository contains the completed assignments.

1. `scan.py` - Pure Python port scanner (socket module).
2. `nmap_scanner.py` - Port scanner using the python-nmap module.
3. `host_discovery.py` - Host discovery tool (Default Gateway & IP Class).
4. `nse_scan.sh` - Bash script to run Nmap NSE scripts.
